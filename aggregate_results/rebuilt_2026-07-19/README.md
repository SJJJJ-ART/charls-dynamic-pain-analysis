# Disclosure-safe rebuilt outputs

This directory contains aggregate results from the 19 July 2026 rebuild. It
does not contain participant identifiers or participant-level records.

The main verification report is `validation_report.md`. The report records
exact cohort checks, numerical agreement for the main models, and one known
warning for the exploratory primary-care interaction. The revised manuscript
uses the rebuilt interaction estimate rather than the archived estimate.

The `figures` directory contains publication figures and the aggregate source
tables used to draw them. Researchers must rerun the analysis from licensed
CHARLS files to recreate participant-level intermediate data.
